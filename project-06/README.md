# Project 06 - Stack Using Dynamic Array

## Description
Implementing a Stack data structure in C++ using Composition with a Dynamic Array.

The Stack class uses the custom Dynamic Array class developed in a previous project as its underlying data structure, reusing its methods to manage elements and perform Stack operations.

The implementation follows the LIFO (Last In, First Out) principle and demonstrates the use of Composition in Object-Oriented Programming (OOP), code reusability, and the implementation of a Stack using a Dynamic Array.

## Language
- C++

## Concepts
- Stack (LIFO)
- Dynamic Array
- Composition
- Object-Oriented Programming (OOP)
- Code Reusability
