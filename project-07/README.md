# Project 07 - Undo & Redo Using Stack

## Description
Implementing an Undo and Redo system in C++ using Stack data structures.

The implementation uses two Stacks to manage changes: one for storing previous states (Undo) and another for storing undone states (Redo).

The system allows users to undo previous changes and redo them when needed, demonstrating the use of Stack (LIFO), Object-Oriented Programming (OOP), and state management.

## Language
- C++

## Concepts
- Stack (LIFO)
- Undo and Redo Operations
- State Management
- Object-Oriented Programming (OOP)
- Stack-Based Implementation
