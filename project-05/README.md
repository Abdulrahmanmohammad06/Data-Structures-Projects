# Queue Using Dynamic Array

## Description
Implementing a Queue data structure in C++ using Composition with a Dynamic Array.

Unlike the previous Queue implementation, which was built using a Doubly Linked List, this project uses the custom Dynamic Array class developed in a previous project as its underlying data structure.

The Queue class reuses the existing Dynamic Array methods to manage its elements and perform Queue operations, following the FIFO (First In, First Out) principle.

This project demonstrates the use of Composition in Object-Oriented Programming (OOP), code reusability, and the implementation of a Queue using a different underlying data structure.
